# 考试证据与搜题交接

## 考试目标

在广东省广州市范围内，按任务的考试类型、年级、学期、考试日期、教材版本及范围版本选取证据。校内期中优先使用已有的教师范围、复习提纲和同校同阶段原卷，再参考广州同年级、同期、范围相近的原卷。家长已说明是同校卷即可登记来源，无需学校全名。广州中考优先本市公开考试资料与历年真题。考试类型变化时，按新类型重新核对证据。广东其他城市仅在考点、学段、范围、层级符合时作辅助。教材一致提高内容可比性，校内或地区命题要求仍需单独核实。

公开研究只收集考试范围、考查标准及原卷证据，优先学校、教育行政或考试机构等原始来源。原卷来源不明时单独标注。用户只要求审核现有题包时沿用项目证据，缺项如实记录。搜索词和公开查询只用考点及考试条件，学生姓名、作答、私人飞书地址和附件不交给外部题库。

逐小问登记来源、考试日期、题号、可见分值、原知识点 ID、必要步骤及实测层级。主考点与辅助考点分别列出。相似试卷反复考查可提高置信度，单次高难考查记作「学校曾考到该层级」，据本次范围及其他试卷判断是否列为必达目标。校方范围排除的项目留在历史或前置队列。缺正式范围时写条件目标，使用原 ID，标明何种证据会改变判断。

| 级别 | 判定依据 |
|---|---|
| L1 | 单知识点直接应用，已知条件直接对应常用步骤 |
| L2 | 同知识点变式，必须从不同表征或情境识别并选择方法 |
| L3 | 两个或以上知识点须联用，前后步骤共同决定结果 |
| L4 | 必须做复杂推导、多条件分支或分类讨论，含边界检验 |

难度标签、题面长度与独立小问数量不直接决定 L 级。以可行的最低解题要求判级。输出原 ID、学科、原章节与名称、目标层级、可观察验收、来源、置信度及尚缺资料。高置信度需校方直接材料或与本次范围一致的充分同校样例。中置信度适用于范围与题型证据部分明确。低置信度适用于范围或深度待定、证据间接或仅有零星样例。孩子的当前层级与稳定性另算。

## 搜题 Skill 交接

将下列要求写进飞书任务的 search_request。字段格式、到期领取和结果回写以 [异步搜题交接](async-selection.md) 为准。通过已配置的入口即时调用时使用同一份要求。审核已有题包时直接使用当前任务的可核实题目。搜题先查广州。广州题源不足时，按任务允许的范围单列广东其他城市候选并标明来源。改变题源范围或目标层级时，按任务明确的放宽条件处理。

每个请求对应一个稳定任务键和一版要求。按知识点或综合目标提供以下内容。

| 输入 | 约束 |
|---|---|
| 任务与作用 | RW、日期、ZSD、前置点或综合组合、初测／补救／迁移／延迟复测 |
| 考试与层级 | 地区填广东省广州市，另填考试类型、年级、学期、教材或范围、考试目标 L 和当日考查 L。 |
| 必测动作 | 卷面上必须出现的作图、列式、变量比较、推理或边界检验，附可接受的等效做法 |
| 检索词 | 核心考点词＋解题动作词＋可换情境词。把必测条件、同义词和剔除条件分列 |
| 来源与放宽 | 来源优先级、允许的后备地区、题型或时期、排除范围、允许放宽的项目 |
| 题量与验证 | 题型、各层题量、预算、需包含原图或表格的要求、已用题及应避开的同模型 |

例如 ZSD-000028 的 L3 交接可用「二次函数 面积分割 割补法 动点 取值范围 最值」。必须由学生自行分割或补形并建立面积函数。单矩形围栏模型只提供约束最值证据。用「广州」「九上」「期中」约束来源，允许的广东后备另列。例子是搜索要求。

要求返回来源题号与链接、来源地区／考试、完整题面及图表、标准答案与解析及其出处、题型、实际 L 级及必测动作、小问映射、耗时、去重键、批次和缺口。既有独立验算答案明确其出处。实际搜不到时返回缺项，保留原目标及地区要求。

## 题包验收

逐小问对照任务目标和原图，重算关键答案、适用条件及边界。核对题干、作答所需图表、答案、解析、评分口径、超范围风险、同模型重复和预计时间。学生版与家长版要抽查公式、关键图和最后一题；对曾有截断风险的导出逐页核对。每题给通过、部分通过或不通过、理由、置信度与可用小问。部分通过时明确哪些小问进入验收；发现题目缺陷时先隔离错误小问及相应判分。判断随 RW 保存，同一道 TM 适用于某任务并不推出它满足其他任务。若需求是只审核，交付题包结论及覆盖缺口即可。
