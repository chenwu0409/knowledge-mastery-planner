## 表结构快照

表内字段按类型归组。查阅字段级写入归属时使用 [飞书读写 SOP](feishu-sop.md)。新建项目按这份结构作为模板，先建表，再建关联，编号由飞书生成，最后验证关系和选项。新 Base 与表 ID 来自创建结果，单独登记项目绑定。字段样式以实际飞书为准。

### 知识点库

显示主字段为「具体考点」。

| 类型 | 字段及约束 |
|---|---|
| 单选 | 训练状态（未开始／进行中／已完成）；建议掌握等级（L1基础／L2熟练／L3综合）；年级（初三）；期中考试价值（高／中／低）；广州中考价值（高／中／低）；学科（数学／物理／化学／道法／历史）；当前掌握程度（未掌握／部分掌握／已掌握） |
| 日期 | 最近复测日期 |
| 文本 | 验收标准；范围版本；考试范围确认依据；范围状态；掌握状态变更历史；二级知识点；预测分值区间与依据；覆盖状态；当前短板与常见错误；章节；核对编号；教材版本；一级知识点；学习状态；具体考点 |
| 关联 | 前置知识点 → 知识点库；后续关联知识点 → 知识点库 |
| 自动编号 | 知识点ID（ZSD-000000） |
| 数字 | 预计中考分值 |

### 考试成绩库

显示主字段为「考试名称」。

| 类型 | 字段及约束 |
|---|---|
| 数字 | 实际成绩；满分；班级排名；年级排名 |
| 文本 | 考试名称；逐题失分与预测校准；失分分析；考试阶段与证据；考试ID；后续改进措施 |
| 关联 | 薄弱知识点 → 知识点库 |
| 日期 | 考试日期 |
| 单选 | 学科（数学／物理／化学／道法／历史） |

考试成绩库保存正式考试记录，按考试 ID 或已核实的考试日期、名称及学科定位。实际成绩、满分、排名只写有证据的数值，薄弱知识点关联原 ZSD。日常训练的评分写作答记录库。
